# CloudPC Android

Install the Android app from the [latest GitHub Release](https://github.com/country2013ball-sudo/Cloud-PC-By-Ak/releases/latest) by downloading `CloudPC.apk`.

The app is a WebView client for a deployed CloudPC web app; it does not host the Windows VM itself. On first launch, use **Set server address** to enter the HTTPS address of your CloudPC web app. Android 6.0 (API 23) or later is required.

Android wrapper source is in [`android/`](./android/).
